# 长沙 · 中原 · 河西走廊 15 日行 — 旅行网站

一个**数据驱动**的个人旅游行程与购票管理网站。行程数据来自用户手写纸质计划照片，购票规则来自 2026-10-11 联网核实。

- 纯静态：HTML + CSS + 原生 JavaScript，无构建步骤、无框架、无外部依赖
- 响应式：手机 / 平板 / 电脑均可阅读与操作
- 六个页面：总览、每日行程、路线地图、购票日历、住宿安排、待办清单
- 待办状态保存在浏览器 `localStorage`，刷新后保留
- 支持导出 JSON、ICS 日历、打印友好视图


页面、样式、逻辑、数据完全分离：**任何日期、车次、酒店、门票的修改都只需编辑 `data/itinerary.json`**，无需改动 HTML / CSS / JS。

## 二、本地运行

因为页面通过 `fetch`/`XHR` 读取 `data/itinerary.json`，**不能直接双击打开 `index.html`**（浏览器会拦截本地文件请求），需要启动一个本地服务器：

```bash
cd travel-site
python -m http.server 8080
# 然后浏览器打开 http://localhost:8080/
```

或者用 Node：

```bash
npx serve travel-site
```

> 如果你直接双击打开 `index.html`，页面会显示一段明确的错误提示，告诉你如何启动本地服务器 —— 不会白屏、不会静默失败。

## 三、如何修改行程数据

打开 `data/itinerary.json`，按下面的结构修改：

| 字段 | 作用 |
| --- | --- |
| `meta` | 标题、起止日期、天数、出行人数、预算、预售规则说明 |
| `stationSaleTimes` | 各车站起售时刻（用于推算开售日期） |
| `transports` | 每一段交通工具（火车/飞机等），含开售日期、时刻、席别、票价、官方入口、状态 |
| `attractions` | 每个景点，含票价、开放时间、预约规则、`extraTransports`（观光车/直通车等子项） |
| `hotels` | 每晚住宿，含入住/退房日期、`nightDates`（连续入住的具体夜晚）、价格、预订状态 |
| `conflicts` | 自动检查出的冲突与建议 |
| `days` | 15 天逐日时间轴（`items` 为时间节点，`ref` 关联到 transports/attractions/hotels 的 id） |
| `todos` | 待办清单 |

**状态取值规范**（请沿用，页面会自动上色）：

- 购买状态：`已购买` / `待购买` / `待预订` / `待预约` / `待确认` / `暂未开放销售` / `不适用`
- 核实状态：`已核实` / `规则已核实，具体时间待确认` / `暂未开放销售` / `待官方确认` / `已购买` / `不适用`

**开售日期怎么算**：中国铁路 12306 预售期为 **15 天（含当日）**，即乘车日前第 14 天开售；各车站起售时刻不同。例如「西安站 11:30 起售」+ 乘车日 2026-10-25 → 开售日 2026-10-11 11:30。

若某车站起售时刻未核实，把 `saleTime` 写成 `"待核实"`，页面会显示「待核实」徽标而**不会**编造一个精确时刻。

## 五、地图方案说明

出于中国大陆地图合规要求，**只使用腾讯地图、高德地图、百度地图**三家合规服务，且**不内置任何地图 API Key**：

- **主方案（全平台可用）**：所有地点与路线均提供**名称检索型地图链接**，点击后在地图 App / 网页中定位或规划路线。这类链接无需密钥，部署到任何地方都能用。
- **增强方案（可选）**：路线地图页会尝试加载腾讯地图 GL JS 组件（走 WorkBuddy 本地代理，前端零密钥）。若当前环境代理不可用（例如部署到公网后），组件会在 6 秒内自动降级，隐藏地图容器并显示提示，**不会留下一个空白/灰色的坏地图**。

## 七、重要声明

- 本网站**只做展示、跳转与管理**，不提供登录、支付或订票功能。真正的购票、预约请在官方平台完成。
- 网站是静态页面，**无法在关闭后主动推送手机通知**。请使用「购票提醒日历（ICS）」导入系统日历，或自行设置手机提醒。
- 票价、开售时刻、预约规则都可能随官方公告调整，出行前请再次核对官方渠道。
